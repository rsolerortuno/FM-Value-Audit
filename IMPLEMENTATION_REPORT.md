# Implementation report — v0.3.0 full-cell and lesion-corrected OOD layer

## Executive summary

v0.3.0 completes the full-cell preprocessing that v0.2.0 could only partially execute. All 174,326
cells across the three cohorts are retained. GSE179994 is converted from R/S4 sparse counts to a
complete H5AD, CSC bundle and sample pseudobulk. A secondary melanoma-to-NSCLC response-transfer
proxy is executed with real Geneformer and scGPT checkpoints.

The largest scientific correction is the outcome unit. The official GSE179994 supplement reports
response per target lesion. P1 and P13 contain discordant lesions, so the prior patient-level mapping
was invalid. v0.3.0 replaces it with 8 responsive and 5 non-responsive lesions across 11 patients,
aggregates repeated biopsies of the same lesion and cluster-bootstraps patients.

The result is useful but not the primary benchmark: Geneformer static embeddings improve over the
direct melanoma response signal and a shape-matched random embedding in the lesion-response proxy,
but do not conclusively improve over manual features. No prospective target-development metric is
computed.

## Outcome reconstruction

The clinical supplement contributes 14 labelled post-treatment biopsy samples. Exact normalised
sample IDs map 13 rows. `P013.post.03` is reconciled to `P13.post.2` only because it is the unique
unmatched post-treatment expression sample remaining for P13; the mapping is explicitly flagged.

After aggregation:

- P1 responsive lymph-node lesion: two biopsies averaged;
- P1 non-responsive right-lung lesion: retained separately;
- P13 responsive liver lesion: retained;
- P13 non-responsive lymph-node lesion: retained;
- total: 8 responsive and 5 non-responsive target lesions across 11 patients.

The generated patient-level response file is removed from the release and marked
`INVALID_NOT_USED` in the Stage-1 audit.

## Response-transfer proxy

The analysis shares 17,999 genes across the three cohorts and evaluates 17,450 genes jointly mapped
to both model vocabularies. Matched ridge heads use the same gene folds and alpha grid. Pretrained
static embeddings are compared with manual features, direct melanoma signal and shape-matched random
embeddings. The fixed melanoma heads are transferred to the NSCLC lesion contrast.

| Method | NSCLC OOD Spearman | Patient-cluster bootstrap 95% interval |
|---|---:|---:|
| Geneformer static | 0.146 | [0.000, 0.187] |
| Manual features | 0.094 | [-0.039, 0.161] |
| scGPT static | 0.071 | [-0.054, 0.132] |
| Direct melanoma delta | 0.062 | [-0.111, 0.158] |

Paired differences:

- Geneformer minus direct melanoma: +0.071, 95% interval [0.005, 0.140];
- Geneformer minus matched random: +0.123, 95% interval [0.005, 0.185];
- Geneformer minus manual features: +0.043, 95% interval [-0.027, 0.109].

Excluding P1 and P13 gives Geneformer Spearman 0.154. Median leave-one-patient-out Spearman is 0.144,
with a range of 0.117–0.164. The observed signal is not driven by one patient, but remains small.

## Scientific boundary

The proxy outcome is a post-treatment expression contrast. It does not encode future clinical
entry, efficacy, safety, tractability or commercial selection. Static token embeddings are not
contextual single-cell embeddings. Pretraining accession overlap remains unresolved.

Therefore the following remain `NOT_COMPUTED`:

- prospective target AUPRC;
- MRR and recall at target-ranking cutoffs;
- excess over historical popularity;
- probability calibration;
- clinical target OOD delta;
- compute-normalised pharmaceutical value.

## v0.4.0 temporal benchmark integration

The release now integrates the completed real temporal protocol rather than leaving its primary
metrics uncomputed. Stage 2A-WIDE defined 17,527 genes across 23 solid-tumour indications and passed
the strict power gate. Stage 2B-WIDE removed 2,343 pre-cutoff clinical pairs and sealed a
gene-disjoint split with 321,222 development rows, 42 development positives, 79,542 holdout rows and
14 holdout positives.

Stage 3A used matched logistic heads, development-only PCA and cross-fitted calibration, then froze
scores and configuration before loading holdout labels. Stage 3B opened the holdout once and ran
2,000 paired target-gene bootstrap replicates.

The confirmatory Geneformer-static-plus-historical contrast against historical features is
-0.00032755 AUPRC, with 95% interval [-0.00948483, 0.00139163]. The conclusion is
`NOT_SUPPORTED`. scGPT static plus historical has the largest observed AUPRC, but it is secondary
and is not promoted post hoc.

Engineering additions include a temporal contract validator, a CLI command, compact hash-linked
reference artefacts and tamper tests. The validator checks 27 invariants. The committed reference is
`PASS_WITH_WARNINGS`: 26 pass and one records the original 14-row Stage 2B aggregate accounting
difference. The source manifests remain byte-exact.

The release does not claim that contextual representations lack value. It evaluates static token
geometry only. The final holdout has been opened and cannot be reused to select contextual models.
